# Rain on Glass

夜の窓ガラスに雨が降り、ピンぼけの通りの明かりが一晩かけて1つずつ消えていく作品です。最後は雨粒の中に朝の淡い青だけが残ります。一晩は3分で、4晩が決まった順で続きます。作成日は 2026-10-01。HTML 1ファイル（790行・45 KB）で、WebGL2 で動きます。画像・ライブラリ・通信は使っていません。

ガラスにピントが合っていて、通りはすっかりぼけています。雨粒は1つずつ小さなレンズになり、奥の明かりを小さく、逆さに、少しくっきりと映します。看板が消えると、その色がすべての雨粒から同時に消えます。夜明けにガラスが曇り、曇りが晴れると次の晩の通りが出てきます。

## 見方

- WebGL2 に対応したブラウザで `opus-5-5/index.html` を開くと、すぐに始まります。操作はありません
- 1周は720秒（180秒×4晩）です。開いたときは1晩目の8秒目、曇りが晴れていくところから始まります
- URL に `#t=97` のように書くと、ループのその秒で止まります。`#t=` を消すと再生に戻ります
- 画面の文字は左下の時刻（2:07 → 5:21 のような夜の時刻）だけです。晩の境目で曇りが濃くなると消えます

## しくみ

- **通り**: 縦の看板、提灯、ネオンの看板5つ、コンビニ（店内・軒の看板）、自販機、窓14枚、ナトリウム灯5本、空と屋根の線、濡れた路面への映り込みでできています。通りは2通りに描きます。1つはくっきりした通りの絵（1024×720、ミップマップ付き）で、雨粒のレンズがこれを映します。もう1つはボケの絵で、明かりを1つずつ解析的な円（角の丸い四角）として半分の解像度で描きます。円は距離で大きさが変わり、縁はやわらかく、縁がわずかに明るく、赤と青で半径を少し変えて色をにじませます。2つ目の絞りの円で切り取って、隅に向かってキャッツアイにします
- **雨**: 雨粒はCPUで1/30秒刻みに動かします。乱数は晩ごとの種から作るので、同じ時刻はいつも同じ絵になります。軒の下は粒が少なく、まばらな場所も残します。粒の大きさはべき乗の分布で、粒どうしが触れると体積を保って合わさります。一定の大きさを超えると、引っかかっては滑りながら蛇行して流れ落ち、跡に小さな粒を残します。流れた跡は曇りを拭い、曇りは時定数22秒で戻ります
- **レンズ**: 雨粒ごとに、粒の中の位置・接触角・半径を浮動小数のテクスチャに書きます。重なったときは高いほうの粒を残します。合成の段で、粒の表面の傾きからスネルの法則で屈折を求め、ガラスの奥の通りのどこが映るかを決めます。こうして小さく逆さの像になります。縁は全反射で暗く、フレネルの反射でかすかに明るくなります。映す像のぼけ方は、粒の大きさから求めたミップマップの段で決めます。粒のあいだの細かい霧の粒は、2層の手続き的な粒で描きます。曇りの濃さに合わせて増減します
- **曇りと境目**: 曇りは奥の光をにじませ、通りの光で柔らかく光ります。晩の境目では、夜明けの青い曇り → 灰色のヴェール → 次の晩の色の順に移ります。前後6秒は2晩ぶんの雨と通りを描いて重ねます。新しい晩の明かりは夜明けの空よりずっと明るいので、重ねる割合を2.5乗で曲げ、遅れて入るようにしています
- **露出**: 晩ごとに、明かりの明るさと空の明るさから露出を決めます。約12秒の時間でなめらかにします。明かりが消えるにつれて露出が開き、夜明けにはさらに +0.75 段開けます
- **プリント**: Dusk と同じ最終工程です。ハレーション（明るい光からの赤いにじみ）、ブルーム、露出が開くほど粗くなる粒子、黒の浮いた階調曲線、ディザの順にかけます。粒子は明るさに応じて大きさの違う層を混ぜ、色ごとに少しずつ変えます。夜明けには焼き付けを冷たく、褪せ方を弱くします
- **再生**: 時間だけで絵が決まります。再生はフィルムのように1秒30コマで、粒子も30コマで変わります。DPR は2まで、出力は約700万画素までにしています
- **軽さ**: M3 の Mac で、1フレームの描画は 1920×1080 で約6〜10 ms、1440×900（DPR 2）で約15〜21 ms です。最初のコマは開いてから約0.2秒で出ます（ブラウザを立ち上げた直後は約1秒）。`#t=` で遠い時刻へ飛ぶと、雨をその時刻まで進めるので0.4〜1.1秒かかります

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) を送りました。人が手を入れたのは、Phase 1 の静止画に「素敵、Phase 2 に進めて」と返した1回だけです
- **Phase 1**: 雨粒とボケの描き方を4通り試しました（[phase1/approaches-contact-sheet.jpg](phase1/approaches-contact-sheet.jpg)）
  - A：雨粒を1つずつ動かし、本当のレンズとして屈折させる。ボケは解析的な円 → 採用
  - B：屈折だけの揺らぎの場 → CG の水に見えた
  - C：絵画風 → どろどろになった
  - D：集めてぼかすボケ → 円が欠けて、どれも同じ大きさになった
  - 静止画は [phase1/](phase1/) にあります。1晩目と3晩目の5つの瞬間（1晩目は25・53.5・122・146・166秒）と、雨粒の 1:1 の切り抜きです
  - Phase 1 の中で直したこと：窓のボケが角張った四角に見えた。雨粒が多すぎて並びが均一だった。接触角が大きすぎて縁の暗い輪が太く、雨粒が濁った。霧の粒がほこりに見えた。夜明けが灰色の石板のようになった
- **Phase 2（仕上げ）**: 主な判断と修正は次のとおりです
  - 晩の境目で、曇りが一瞬クリーム色や桃色に転んだ。露出が夜明けのまま開いていたところへ、次の晩の明るい明かりが入ったため → 露出を晩ごとに持ち、重ねる割合で混ぜるようにした。曇りの色を暗めにし、新しい晩の明かりは重ねる割合を2.5乗で遅らせた
  - 夜明けの始まりを晩ごとに8〜9秒早めた（104〜112秒）。淡い青の時間を長くするため
  - 開発用の描き方の切り替えを取り除いた
  - 開いた直後の最初のコマに約1.3秒かかった。0秒目は境目なので、2晩ぶんの雨を進める必要があったため → 再生は8秒目から始めるようにした（約0.2秒）

## 確認したこと

- **全コマ**: 720秒を1秒1コマ（640×360）で書き出し、60コマずつ12枚のシートで全部見ました。最後の版は [loop.jpg](loop.jpg) です。失格項目にあたるコマはありません。各晩の境目で曇りがいちばん濃い数コマ（4晩で約16コマ）は、ほぼ淡い色だけの画面になります。それを除いても、壁に飾れるコマは97%以上と判断しました
- **縞**: 夜明けの空（160秒・335秒・520秒）、最後の数時間の暗い画面（128秒）、曇りの境目（176秒・184秒）を 1600 px 幅で書き出しました。1:1 で、3本の帯の行ごとの明るさの残差を測っています。いちばん大きい値は雨粒とボケの輪郭でした。粒子を横方向に消して残差を8倍にした画像でも、等高線のような段はありません。滑らかな部分を 1:1 で切り抜き、明るさを1〜99%に引き伸ばしても、縞は見えませんでした
- **つなぎ目**: ループ全体で前のコマとの差を測りました。目立って大きいのは、看板やコンビニが消える瞬間だけです（意図どおり）。境目の0・180・360・540秒の前後は2秒刻みでも見て、夜明けの青い曇り → 灰色のヴェール → 次の晩の色、と切れ目なく移ることを確かめました。720秒目から0秒目へも同じようにつながります
- **画面**: 1600×900、1920×1080、1440×900（DPR 2）で確認しました。コンソールのエラーはありません。動作確認は M3 の Mac 上のヘッドレス Chromium（Metal）で行いました
