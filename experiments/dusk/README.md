# Dusk

ひとつの海の水平線で、日が沈んだあとの夕暮れが30秒ずつ、6晩続けて流れる作品です。作成日は 2026-09-30〜10-01。HTML 1ファイル（748行・50 KB）で、WebGL2 で動きます。画像・ライブラリ・通信は使っていません。

場所はポルトガルのロカ岬で、崖の上から西の大西洋を見ています。太陽はもう沈んでいて、残照・ブルーアワー・星だけを描きます。晩ごとに日付と空気が違うので、光の帯の位置、色、海に映る色、出てくる惑星が変わります。夜まで行くと、次の晩の残照へゆっくり溶け替わります。

## 見方

- WebGL2 に対応したブラウザで `opus-5-5/index.html` を開くと、すぐに始まります。操作はありません
- 1周は180秒（30秒×6晩）です
- URL に `#t=97` のように書くと、ループのその秒で止まります。`#t=` を消すと再生に戻ります
- 画面の文字は隅の撮影メモ（緯度・経度・日付）だけです。2020年1月23日の晩だけ、金星の映り込みとぶつからないように右下に出ます

## 1晩の流れ（30秒）

| 秒 | 太陽の高さ | 起きること |
| --- | --- | --- |
| 0–6 | −2° → −4° | 前の晩の夜が溶けて、淡い残照の空になる |
| 6–12 | −4° → −6° | 明るく淡い空。水平線の帯に色が集まり、海に映る |
| 12–22 | −6° → −12° | ブルーアワー。帯が細く濃くなり、帯の色が海に赤く映る。惑星が出る |
| 22–30 | −12° → −18° | 帯が線になって沈み、星が明るい順に出てくる。プリントは夜の青い黒に寄っていく |
| 30–36 | −18° → −24° | 天の川の出る夜。次の晩の0–6秒と重なって溶け替わる |

## しくみ

- **大気**: 空気分子の散乱（Rayleigh）、エアロゾルの散乱（Mie）、オゾンの吸収、ピナトゥボの晩だけ高さ 21 km の硫酸の層を入れています。エアロゾルは晩ごとに量・粒の大きさ・吸収・層の高さを変えます。透過率（256×64）と多重散乱（128×32）は起動時に表にし、空はカメラから見た方向の表（320×192）を毎フレーム1回、80段の積分で描きます。地球の影は積分の1段ごとに解析的に求め、ぼかした境目で入れています
- **太陽と星**: 日付とロカ岬の緯度・経度から、太陽の方位と天体の位置を計算します。夏は光の帯が北西に、冬は南西に寄ります。太陽は36秒で −2° から −24° まで、はじめはゆっくり、だんだん速く沈みます。星は明るい星約190個の実際の位置と等級に、日付から計算した惑星と、天の川のほうへ密になる暗い星7000個を足しています。明るい星と惑星は、海に長く柔らかい光の柱として映ります
- **海**: うねりとさざ波を晩ごとに変えます。空を6段階にぼかした表を作り、波の傾きの散らばりに合わせて選んで映します。映り方はフレネルの式に従います
- **露出**: 0.5秒ごとに空の明るさを起動時に測っておき、空が明るくなるときはそのまま追い、暗くなるときは86%だけ開けます。それを約4秒かけてなめらかにします。さらに空だけに局所的な段階フィルターをかけ、明るい帯を抑えて暗い空を持ち上げます（明るさの −0.7 乗、×0.3〜×2.2 でやわらかく頭打ち）。帯と空の差を2〜3段に収めるためです。そのため、ブルーアワーも夜も黒くつぶれません
- **プリント**: 晩ごとに6種類のプリント（黒の浮き具合、白の色、焼き付けのフィルター）を使い分けます。太陽が −8° から −13.5° に沈むあいだに、どの晩も同じ「青い墨のような夜」のプリントに寄せます。最後の工程で、ハレーション、粒子、プリントの階調曲線、ディザをかけます。ハレーションは明るい部分からの赤いにじみです。粒子は明るさに応じて大きさの違う層を混ぜ、色ごとに少しずつ変え、露出が開くほど粗くします。ディザは縞を出さないためです
- **再生**: 時間だけで絵が決まります。再生はフィルムのように1秒30コマで進み、粒子も30コマで変わります。画面の更新が120 Hz でも描くのは30回です。DPR は2まで、出力は約830万画素（4K相当）までにしています
- **軽さ**: M3 の Mac で、1フレームの描画は 1920×1080 で約5 ms、1440×900（DPR 2）で約9 ms、2560×1440（DPR 2、内部は DPR 1.5）で約13 ms です。30コマなので GPU の使用はそれぞれ約15%・27%・40%です。溶け替わりの6秒間は2晩ぶん描くので、空と海の分が倍になります。起動から最初のコマまでは約0.1〜0.25秒です

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) を送りました。人が手を入れたのは3回です。Phase 1 の途中で止めて方向を変えたのが2回、Phase 1 の静止画に「素敵、Phase 2 に進めて」と返したのが1回です（詳しくは prompt.md）
- **Phase 1 v1**: プロンプトどおり5か所（太平洋の赤道付近、ルブアルハリ砂漠、テイデ山の雲海の上など）を巡り、太陽の円盤と雲を描く版を作っている途中で止まりました
- **Phase 1 v2（方向転換のあと）**: 日の入りの強い光・雲・建造物をなくし、1か所・1アングルにしました。淡い夕暮れの色の違いを、場所の数ではなく日付と大気とプリントで出しています。静止画は [phase1/](phase1/) にあります。1991-10-06 と 2020-01-23 は5つの瞬間（各晩の7・13・19・24・29秒）、ほかの4晩は淡い時間を1枚ずつです
- **Phase 2（仕上げ）**: 主な判断と修正は次のとおりです
  - 露出計の空の測り方がずれて、露出が小刻みに揺れていた → 測る方向を正しく取るよう直した
  - 光の帯だけが明るく、空と海が暗く沈んでいた → 空だけにかける局所的な段階フィルターを入れた。高さだけで決めると帯の横に暗いくさびが出たので、方位にも沿って測るようにした。上限を固く切ると輪郭がマッハバンドの弧になったので、やわらかく頭打ちにした
  - 夜が茶色がかった灰色になった（暖かいプリントの黒のため）→ 夜に向けて全晩を青い黒のプリントに寄せ、露出計には大気光の明るさを足して開けすぎを止めた
  - 夏のもやの晩に、地球の影の境目が硬いくさびになった → 影の境目のぼかしを広げた
  - もやと砂塵の晩で、左の空が18秒あたりで急に暗くなって止まった。0.2秒刻みの比較で見つかった → 多重散乱の表が太陽の高さ方向に3.7°刻みしかなく、補間の折れ目が出ていた。128段（0.9°刻み）にして消した。正しく計算すると影の空が灰色に寄ったので、その2晩のプリントの黒を青く寄せた（暗部は寒色、明部は暖色）
  - 2020-01-23 の終わりに、金星の映り込みが左下の撮影メモに重なった → この晩だけ撮影メモを右下に出す
  - 2560×1440（DPR 2）では描画が21 msかかった → 1秒30コマで描き、出力を約830万画素までにした（13 ms）

## 確認したこと

- **全コマ**: 180秒を1秒1コマ（1600×900）で書き出して全部見ました。上の修正のたびに描き直し、最後の版で5回目です。最後の版は [loop.jpg](loop.jpg) です
- **縞**: 全180コマで、空を3本の帯（左・中央・右）に分け、1:1 で縦方向の明るさの残差を測りました。540か所のうち475か所は 1.2/255 以下でした。残りの65か所は、地平のすぐ上で帯が急に明るくなる曲がり目、金星のにじみ、星の集まりです。そのうち4か所は 1:1 で拡大して、段がないことを確かめました。代表6コマは、粒子を横方向に消して残差を8倍にした画像でも見ています。等高線のような段はありません。縮小したコンタクトシートでは輪のような縞が見えることがありますが、1:1 で見ると出ていません（縮小で粒子が折り返すため）
- **つなぎ目**: ループ全体を0.2秒刻みで描き、前のコマとの差を測りました。溶け替わりの6秒間は、差がなめらかな山形に上がって下がります（最大 3.2/255）。それ以外は最大 2.2/255 で、前後より急に大きいコマはありません。撮影メモは、溶け替わりの45%までに消え、60%から次の晩のものが出ます。右下への移動は消えているあいだに行います。180秒目から0秒目へも同じようにつながります
- **画面**: 390×844（DPR 3）、1440×900（DPR 2）、2560×1080、2560×1440（DPR 2）で構図と 1:1 の粒子を確認しました。コンソールのエラーはありません。動作確認は M3 の Mac 上のヘッドレス Chromium（Metal）で行いました
