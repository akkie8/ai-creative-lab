# Carrow Lensing

光が「より暖かい光のほうへ曲がる」宇宙を描いた生成アート。作成日: 2026-09-30。HTML 1ファイル（522行・31 KB）、WebGL2 で動き、画像・ライブラリ・通信はありません。

暗闇に淡い光の筋が落ち、その中で暖かい光の玉がひとつずつ灯ります。灯るにつれて、そばを通る光が玉のほうへ引き寄せられ、玉のうしろで柔らかい炎のような焦点に集まっていきます。

## 見方

- WebGL2 に対応したブラウザで `opus-5-5/index.html` を開くと、すぐに始まります
- URL の `#seed=22` でシードを指定します。指定がなければランダムに選び、URL に書き込みます

- おすすめは `#seed=22`（琥珀色の2つの炎）、`#seed=24`（交差する2本の筋に3つの玉）、`#seed=1`（ひとつの焦点）

## しくみ

- **法則**: 暖かい光が出ているところでは、それより冷たい光が遅くなる（屈折率が上がる）。屈折率は n = 1 + κ·c(T)·W(x)。W は玉が出す暖かい光のガウス分布、c(T) は通る光自身の色温度で、暖かい光ほど少し強く曲がる。光線は d/ds(n t̂) = ∇n に従って進む。詳しくは [LAW.md](opus-5-5/LAW.md)
- **炎の正体**: ガウス型の屈折率はひどい球面収差のあるレンズになり、中心寄りの光は近くで、外寄りの光は遠くで焦点を結ぶ。その結果、焦点は点にならず、細長く柔らかい「炎」の形（コースティクス）になる
- **光線追跡は GPU で**: 1本の筋を12の色帯×128本の光線で表し、フラグメントシェーダで RK2 積分する。隣り合う光線の間を「光の管」として面で塗るので、光のエネルギーが正確に保たれ、光線が交差して折り返すところもつぶれない
- **カメラ**: 奥行き4層の浮動小数点バッファに光をためて、層ごとにボケをかける（奥ほど大きい）。そのあとベーリンググレア、色相を保つトーンマップ、フィルムの粒子、ディザ。グラデーションに縞は出ない
- **同じシードなら同じ絵**: シード付き乱数と固定の時間刻みを使う。状態は0.25秒ごとに計算し、その間は補間する（誤差 0.3/255 未満）。画面の大きさやフレームレートが変わっても、同じシードは同じ絵に育つ。露出はシードごとに完成時の絵から決めている
- **軽さ**: M3 で1080p の状態計算が1回約19 ms、0.25秒に1回なので GPU の約7%。表示は1フレーム1〜2 ms で、60fps を保つ。DPR は2まで

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) を1回送りました。人が手を入れたのは、Phase 1 の5つの法則から caustic（Carrow Lensing）を選んだ1回だけです
- **Phase 1（探索）**: 5つの法則を考えてプロトタイプを作り、各6シードのコンタクトシートを出して止まるまで。途中で6つの法則を「美しくない」として差し替えています（[phase1/README.md](phase1/README.md)）
- **Phase 2（本番）**: 選ばれた法則を index.html 1枚に作り込むまで。主な判断と修正は次のとおりです
  - Phase 1 の試作は CPU で光線を追い、1本ずつ柔らかい線として描いていた → 灯っていく途中の絵を何度も描き直す必要があるので、GPU の光線追跡と光の管の描画に作り直した
  - 32bit 浮動小数点のテクスチャを線形補間で読んでいたため画面が真っ黒になった → 最近傍で読むよう直した
  - 最速のシードが43秒で完成してしまった → 玉の灯る時間を延ばし、5000シードで45〜64秒に収めた（完成した絵は変わらない）
- **検証**: 24シードを 1920×1080 で完成まで描き、22シードが「壁に飾りたいか」に合格（11と14は保留で不合格扱い）。1:1 の拡大（DPR 2 を含む）で縞と粒子を確認し、シード 4・6・22・24 は育つ過程を最初から最後まで見ました。4:3・16:10・2.37:1 の画面比、ハッシュの書き込み、クリック・スペース・溶け替わりも確認しています。動作確認は M3 の Mac 上のヘッドレス Chromium（Metal）で行いました
