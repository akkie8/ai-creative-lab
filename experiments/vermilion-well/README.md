# Vermilion Well

15秒でループするモーショングラフィックス。作成日: 2026-09-25。HTML 1ファイル（434行・約27KB）だけで動きます。画像・動画・ライブラリは一切使わず、絵はすべて WebGL2 のシェーダで毎フレーム計算しています。

- ギャラリー: https://akkie8.github.io/ai-creative-lab/works/vermilion-well/
- 動画: `vermilion-well.mp4`（1920×1080 / 60fps / 15.0秒 / H.264 40Mbps / 約70MB）。容量が大きいのでリポジトリには含めていません。下の「MP4 の書き出し」で作り直せます
- 作品: [opus-5-5/index.html](opus-5-5/index.html)
- プロンプト: [prompt.md](prompt.md)

## 見方

- WebGL2 に対応したブラウザで `opus-5-5/index.html` を開くと再生が始まります
- クリックで全画面、Space で一時停止。マウスを止めるとカーソルが消えます

  - `?sheet=0,3,6,9,12&cols=3` … 指定した時刻のコマを並べて1枚で表示

## 15秒の流れ

| 秒 | 起きること |
| --- | --- |
| 0–0.4 | 朱色の地に、平らな黒い円（最後のコマと同じ絵） |
| 0.4–1 | 光が入り、円が漆のような黒い球だったと分かる。背景の朱は真上から見た「床」 |
| 1.0–2.6 | 5回分裂して 1個 → 32個 |
| 2.6–3 | いったん縮んでから、弾ける |
| 3–4.6 | 群れになって宙を舞い、息を吸うように一度浮き上がる |
| 4.6–8 | 雨になって落ち、朱の床が「海」になる。着水するたびに王冠と波紋 |
| 6.4–12.4 | カメラが海面すれすれを滑る。海が漏斗状にへこんで渦になり、中心の黒い目に吸い込まれていく |
| 12.4–14.4 | カメラが真上へ抜け、渦が逆回転。輪が走り、渦の中心が穴に変わる |
| 14.35–15 | 穴が平らな黒い円になり、最初のコマに戻る |

「予想外」の変化は3つです。平らな円が実は立体で、分裂すること。群れが雨になり、背景だった朱が海になること。海が渦を経て穴になり、その穴が最初の円になること。

## しくみ

- **立体は数式で描く**: 1ピクセルごとにカメラから視線を飛ばし、球や海面の数式とぶつかる点をGPUで求めます（レイトレーシング／レイマーチング）
  - 分裂: 近い球どうしが溶け合うように計算するので、くびれてちぎれる
  - 雨: 最大150個の球を、落ちる速さに応じて縦に伸ばす。影と映り込みも計算
  - 海: 高さを返す関数。雨粒の着水位置と時刻から波紋を立て、うねり、渦巻き、漏斗、最後の穴を重ねる
- **動きはすべて時刻 t の関数**: 物理シミュレーションを積み上げず、「t秒のとき、この球はここ」を毎回直接計算します。弾ける、落ちる、着水する時刻も式で求めています。カメラはキーとなる位置をなめらかな曲線（エルミート補間）でつなぎます。状態を持たないので、どの瞬間も同じ絵を再現できます
- **印刷物に見せる2パス構成**: 1パス目で3Dの絵を「黒・朱・紙」の濃さ1つだけで描きます。2パス目でそれを3色のインクに刷り分け、中間の濃さは網点に変えます。衝撃の瞬間ほど版ズレが大きくなり、紙の質感もコードで作っています
- **最初と最後が同じ絵になる理由**: 冒頭と終わりの一瞬は、光を切って平らな円だけを描いています。最後の穴は、最終的なカメラの高さから見て最初の円と同じ大きさになるよう半径を逆算しています
- **軽くする工夫**: 3Dの1パス目は画面より低い解像度で描き、2パス目で画面解像度のまま2値化するので、輪郭はくっきり保てます。フレーム時間を見て内部解像度を自動で上下させます（上限は約240万ピクセル、DPRは2まで）

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) のプロンプトを1回送っただけで、追加の指示はしていません
- コンセプトから実装まで Claude が決めました。指定した時刻のコマを並べた一覧を自分で撮っては見て、直す作業を繰り返しています。主な修正は次のとおりです
  - 床のテカリが大きくぼやけていた → 鋭い太陽の映り込みに変え、球の後ろから日食のように現れる形にした
  - 海と渦が単調、または真っ黒 → 漏斗の深さと幅、波の立ち方、カメラの軌道を作り直した
  - 12.4秒以降が真っ白 → カメラ計算の差分が NaN になるバグだった
  - 穴の中心が赤く抜けた → もや（遠くを霞ませる処理）と暗くする処理の順番を入れ替えた
  - 海のパートが寂しい → 遅れて落ちる雨粒を28個足した
- 制作に使ったMacでの計測（1080p、内部解像度0.6倍）: いちばん重いコマで14.4ms、大半は1〜11ms

## MP4 の書き出し

900コマ（60fps × 15秒）を、時刻 i/60 で1枚ずつ 4K（3840×2160）で描いて 1080p に縮めます。それを macOS 標準の AVFoundation（Swift）で H.264 にエンコードするので、ffmpeg は不要です。

```bash
python3 export/srv.py
```

`experiments/vermilion-well/` で実行します。起動したらブラウザで http://127.0.0.1:8918/ を開くと書き出しが始まります。900コマ終わると `vermilion-well.mp4` を上書きしてサーバーも止まります（制作に使ったMacで約11分）。

- `swiftc`（Xcode Command Line Tools）が必要です。初回に `export/enc` をビルドします
- 出力先を変えるときは `python3 export/srv.py 出力先.mp4`
