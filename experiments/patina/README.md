# Patina

開くたびに新しい古い金属の板が1枚生まれる作品です。まだらの緑青の上を、錆の粒の帯が天の川のように横切ります。作成日は 2026-10-03。HTML 1ファイル（605行・39,767 bytes）で、WebGL2 で動きます。画像・ライブラリ・通信は使っていません。

板は正面から見ていて、画面いっぱいに広がります。緑青は何十年分の雨と露で育てた層で、錆の粒は板に落ちた鉄の粒がその場で錆びて広がったものです。粒には黒茶の酸化の芯とオレンジや金の身があり、大きいものは厚く盛り上がって、まわりの緑青に錆のしみがにじみます。重い粒の下には、ときどき錆汁が垂れています。仕上げはカラーネガのプリントで、絵が出来上がったあとはフィルムの粒子だけが動きます。

## しくみ

- **板の結晶**: まず板全体に、結晶の粒・粒の集まり・その境目を描きます。あとの成長はすべてこの粒の中を進むので、ノイズの模様ではなく結晶の肌に沿った形になります
- **天気**: 360日ぶんの雨と露を GPU で計算します。1日ごとに大きさの違う水滴が板を濡らし、しばらく留まって乾き、縁に塩の輪を残します。一部の日は水が下へ流れます。濡れた回数・塩の輪・流れた水・大雨の回数を浮動小数のテクスチャに積み上げます
- **緑青の層**: 金属の上に深い殻を1枚、その上に若い殻を4枚、時代順に重ねます。殻はそれぞれの核から、結晶の粒と濡れ方で決まる通りにくさの場を通って広がります（first-passage growth。各画素に「いちばん安い道で残った予算」を持たせ、8方向に max-plus で伝えます）。核は1つではなく中くらいの尺度の場に沿って群れで置くので、丸いコインや迷彩柄になりません。殻の縁は予算をノイズでずらして、線で終わらず粒の中にほどけさせます。水が留まったところは深く暗く、流れたところは粉っぽく淡くなります
- **錆の粒**: 帯の中に鉄の粒を1〜2万個落とします。7割は群れで、帯に沿った密度の波で集まり、まばらになります。大きさはべき乗の分布で、上限があります。帯の濃いところには、大きな塊（主な瘤1つと、くっついた5〜14の小さな瘤）を数個置きます。粒はそれぞれ結晶の粒の中を72·PPU 回の成長で広がり、どの粒が勝ったか（大きさと金の割合）を持ちます
- **錆の色**: 殻は厚いところほど暗く、でこぼこになります。色の区分は中心からの距離ではなく、絶対的な厚さに中くらいの尺度のノイズを足したもので決めます（距離の比で決めると、花や的のような同心円になりました）。薄いところは黄褐色からオレンジや金、厚いところは赤茶、いちばん厚い芯は黒茶の酸化物です。酸化物はまだらで、ところどころ剥がれて、下の新しいオレンジがのぞきます。小さな粒はしみだけです
- **しみと錆汁**: 大きな殻のまわりには、殻の位置だけを σ13 でぼかした場を作って、緑青に錆色のしみを強くにじませます。重い粒のうち上位3つは、下へ進みやすく横へ進みにくい成長で錆汁を垂らします。垂れは横に柔らかくならし、水の通り道の筋で細い流れに分けます
- **光**: 曇りの日の拡散光です。高さから法線と遮蔽を求め、盛り上がった殻と錆がかすかに光を受けます。光沢はごく弱くしています。最後に古いレンズのように少しだけぼかします
- **プリント**: 平均の緑青が種ごとの明るさに来るよう露出を決め、ロジスティックの階調曲線（浮いた黒、柔らかい肩、影は冷たくハイライトはクリーム色）を通します。粒子は明るさで大きさの違う層を混ぜ、影と中間で粗く、ハイライトで細かく、色ごとに少し変えます。最後にディザをかけます
- **現像**: 計算は12 ms ずつに分けて少しずつ進めます。終わったら、プリントのミップマップのぼけた段から始めて、濃度を上げながら細かい段へ下りていきます
- **軽さ**: M3 の Mac のヘッドレス Chromium（Metal）で、計算は 1600×1000 で約0.3〜0.9秒、1440×900（DPR 2）で約2秒です。現像は約11秒です。完成後は粒子だけを1秒24コマまでで描き直します（ヘッドレスでは約20コマ）

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) を送りました。人が手を入れたのは、Phase 1 の静止画に「もっと大胆で生々しい錆にできる？」と返した1回と、その静止画に「Phase 2 に進んで」と返した1回だけです
- **Phase 1**: 表面と錆の粒のつくり方を3通り試しました（[phase1/approaches-contact-sheet.jpg](phase1/approaches-contact-sheet.jpg)。左から A・B・C。参考画像は第三者の写真なので、シートから外しています）
  - A：結晶の粒の中を進む成長（first-passage growth）で緑青の層と錆の粒を育てる → 採用
  - B：粒子を積もらせてから、拡散で錆をにじませる → 紙やすりのように見えた
  - C：浸食と反応拡散（Gray-Scott）のしみ → 輪や迷路の模様が出た
  - Phase 1 の中で直したこと：殻の核が1つずつで、丸いコインや迷彩柄になった。明るい殻と粉の不透明度が高く、遠くから見てテラゾーのようにうるさかった。小さな連番の種をそのまま乱数に入れて、12枚中8枚が同じ明るさ、12枚とも1本の帯になった。重みの裾の長い群れが、べったりしたオレンジの塊になった。プリントの曲線が硬すぎた
- **返信「もっと大胆で生々しい錆にできる？」**: 静かな緑青はそのままで、錆の側を大きく、厚く、暗くしました
  - 主な瘤と小さな瘤がくっついた大きな塊を加え、成長の回数を増やした
  - 錆の色の区分を、中心からの距離の比から絶対的な厚さに変えた。比で決めると花や的のような同心円になった
  - 錆汁を加えた。最初は三角の歯のような形になり、次は細い柱が筋の中に消えて見えなかった。下へ進みやすい成長のあとで横にならし、太い源を持たせて直した
  - しみは、成長の副産物のしみだと隣の小さな粒に負けて見えなかった。大きな殻の位置をぼかした別の場を作り、強い錆色で混ぜた
  - 平たい暗い円盤に見えた殻に、まだらの酸化物、剥がれ、ふくれの明暗と高さを加えた
- **Phase 2（仕上げ）**: 主な判断と修正は次のとおりです
  - 採らなかった B と C の描き方と、開発用の切り替えを取り除いた
  - 48の種を見たら、錆汁が三角の歯に戻った種（s20）と、帯がスプレーのようにきらきらした種（s4・s15・s29・s30・s40）があった
  - 錆汁は、候補を重い順に並べて上位3つだけにした。中くらいの粒が先に枠を使い切っていたため
  - 粒の7割を群れにした。白い点の割合を1〜3.5%に、水色の鉱物の不透明度を 0.55〜0.72 に下げて、きらきらを抑えた

## 確認したこと

- **48の種**: 種1〜48を 1600×1000 で描き、12枚ずつ4枚のシートで全部見ました（納品版をまとめたもの：[seeds.jpg](seeds.jpg)）。壁に飾れると判断したのは48枚中44枚です。残る4枚（s4・s15・s30・s40）は帯が濃く、遠くからはややきらきらして見えます。1:1 では本物の飛び散りに見えます。失格項目にあたる種はありません
- **縞**: 暗く沈む種（s23・s43）と淡い種（s7）を 1:1 で切り抜きました。大きな尺度の明るさ（σ120 のぼかし）を引いて8〜10倍に引き伸ばしても、等高線のような段はありません。滑らかな色だけになる現像の初めのコマ（1秒目と3秒目）も8倍に引き伸ばして、段やミップマップのブロックがないことを確かめています
- **現像**: s7 と s23 で、0.3・1・2・3・4.5・6・8・11秒のコマを見ました。白い紙 → 柔らかい色 → ぼけた帯 → 細部の順に進み、途中で汚くなるコマはありません
- **画面**: 1600×1000、1280×800、2560×1080（ウルトラワイド）、1440×900（DPR 2）、1920×1080 で見ました。板は画面の大きさに合わせて広がり、帯と余白の釣り合いは崩れません。コンソールのエラーはありません。動作確認は M3 の Mac 上のヘッドレス Chromium（Metal）で行いました
- 色の幅は狭めです。翡翠や灰緑の種も、並べるとほとんど青緑に見えます。ミントや彩度の高い緑に寄るのを避けたためです
