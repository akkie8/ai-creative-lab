# MISREGISTERED

20秒でループするモーショングラフィックス。作成日: 2026-09-25。HTML 1ファイル（1,005行・54,182 bytes）だけで動きます。画像・動画・ライブラリ・Webフォントは使わず、端末にある書体を読み込んで、印刷のしくみごとブラウザの中で毎フレーム「刷って」います。

テーマは「印刷の失敗が振り付けになる」。3版（黒・蛍光の赤橙・コバルト）のポスターが見当ズレを起こし、網点に溶け、刻印され、裁断され、組み直されて、一瞬だけ完全に見当が合う——PERFECT IS BORING.——そしてまた小さな誤差から冒頭のポスターに戻ります。

- 作品: [opus-5-5/index.html](opus-5-5/index.html)
- プロンプト: [prompt.md](prompt.md)

## 見方

- WebGL2 に対応したブラウザで `opus-5-5/index.html` を開くと再生が始まります。操作やUIはありません
- 16:9 がいちばんきれいに収まります。縦長の画面では、横長のポスターが紙の中央に置かれた見え方になります
- `#t=8.6` のように URL の末尾に時刻を付けると、その時刻で止まります（ページの再読み込みは不要）
- 右上の `FRAME` と上辺の `IMPRESSION`（刷り枚数）はループで戻らず増え続けます。数字からループの継ぎ目が分からないようにするためです。刷り枚数は PERFECT IS BORING. が刷られた瞬間に1つ増えます

## しくみ

- **書体は端末のものを使う**: 起動時に Canvas 2D で Helvetica Neue（なければ Helvetica → Arial → Liberation Sans など）を描き、距離場（SDF）の文字アトラスを作ります。レイアウトは実際に測った字幅・カーニングから組むので、書体が変わっても構図が崩れません
- **1文字＝1枚の四角形**: 文字・罫・円・トンボはすべて GPU のインスタンス描画で、各版（黒・赤・青）のチャンネルに書き込みます。書き込み先は「網点にかかるトーン」と「網点にかからない線画」の2枚。抜き（ノックアウト）もここで処理します
- **印刷パス**: 2枚の版を画面に刷ります。版ごとに見当（位置・回転）、スクリーン角度、線数、網点の形（丸 → 市松 → 白抜き、線スクリーン）を持ちます。途中からは「セルが覆うインク量で丸の大きさが決まる」本物の AM 網点に切り替わり、文字が大きな丸の集まりに分解されます
- **インクと紙**: インクは膜の厚さで光を吸う（Beer–Lambert）半透明の層として掛け合わせるので、赤と青の重なりは自然に暗い紫になります。濃度ムラ、紙の繊維に沿ったかすれ、インクの乗らない点、ドットゲイン、縁の荒れ、紙の繊維と歯、まれな異物もコードで作っています。Display P3 の画面では蛍光色を P3 のまま出します
- **動きはすべて時刻 t の関数**: 状態を持たないので、どの時刻でも同じ絵が再現できます。見当ズレ・カメラ・スクリーン角度はキーフレームの軌道で、ゆっくり動くところと「カチッ」と止まるところ（バウンドして止まるイージング）を使い分けています
- **ループの継ぎ目**: 18.9秒以降と0秒は同じ関数で描く同じ絵です。継ぎ目は静止の真ん中にあります
- **軽くする工夫**: インクのない場所は版の縮小画像で判定して計算を飛ばします。フレームが落ち続けると内部解像度を段階的に下げます（DPRは2まで、上限は約840万ピクセル）

## 制作の流れ

- Claude Code（Opus 5.5）に [prompt.md](prompt.md) のプロンプトを1回送っただけで、追加の指示はしていません
- コンセプトから実装まで Claude が決めました。ヘッドレス Chromium で指定時刻のコマを撮り、コマ一覧・1/15秒刻みのフィルムストリップ・等倍の拡大を見ては直す作業を繰り返しています。主な修正は次のとおりです
  - 黒1色の FORM がグレーに見えた → インクの濃さを「覆う面積」ではなく膜の厚さとして掛けるよう直した
  - 何も刷っていない紙に薄い点が並んでいた → 網点のアンチエイリアスのにじみ。トーン0では必ず0になるようにした
  - インクのムラが四角いブロック状に見えた → ぼかしたノイズのチャンネルを作り、ムラをなめらかにした
  - FORM に裁断前から細い継ぎ目が見えた → 裁断の瞬間までは1枚のまま描くようにした
  - 網点の影が黒の中にも透けて黒が濁った → 影を黒の下で抜き、細いトラップだけ残した
  - クライマックスで巨大な黒い文字が塊になって読めなかった → 各行が版ごとに遅れて滑り込む動きに作り直した
  - PERFECT IS BORING. から MIS / REGIS / TERED への組み替えがごちゃついた → 「誤差が広がる」と「植字機が組む」の2段階に分けた
  - 拡大したトンボの縁が手描きのように波打った → 縁の荒れに画面上の上限をかけた
  - 右余白の縦書き注記がトンボの拡大と重なった → 注記の位置を移した
- 動作確認は GPU のない Linux 上のヘッドレス Chromium（SwiftShader）で行いました。実機（GPU）でのフレーム時間は未計測です
- 生成時間・トークン数は記録していません

## MP4 の書き出し

1200コマ（60fps × 20秒）を、時刻 i/60 で1枚ずつ 4K（3840×2160）で刷って 1080p に縮めます。エンコードは Vermilion Well と同じ macOS 標準の AVFoundation（Swift）で、ffmpeg は不要です。

```bash
python3 export/srv.py
```

`experiments/misregistered/` で実行します。起動したらブラウザで http://127.0.0.1:8919/ を開くと書き出しが始まり、1200コマ終わると `misregistered.mp4` を書いてサーバーも止まります。

- `swiftc`（Xcode Command Line Tools）が必要です。初回に `../vermilion-well/export/enc.swift` から `export/enc` をビルドします
- 出力先を変えるときは `python3 export/srv.py 出力先.mp4`
- `--dry` を付けるとエンコードせず、ブラウザから届いたコマ数だけ数えます
- 書き出しでは FRAME が 0 から、IMPRESSION が 000417 から始まります
